# Лабораторная работа №2 — Базовые и продвинутые возможности CSS

## Описание
Оформление страницы из ЛР №1 с помощью CSS. Реализован стиль «металлик» с тенями, 
CSS-переменные, позиционирование, псевдоклассы состояний и адаптивная вёрстка.

**Вариант:** 12  
**Тема:** Техногик и обзорщик гаджетов  
**Стиль:** Металлик, серебристо-чёрная цветовая гамма

## Цель работы
Научиться подключать стили, работать с селекторами, типографикой, цветами,
отступами, позиционированием и псевдоклассами.

## Требования и реализация

### 1. Три способа подключения стилей
| Способ | Где реализовано | Что стилизует |
|--------|----------------|---------------|
| **Внешний файл** (`style.css`) | `<link rel="stylesheet" href="style.css">` | Основной стиль всей страницы |
| **Внутренний блок** (`<style>`) | В `<head>` файла `index.html` | Высота и шрифт полей ввода (`input`, `textarea`) |
| **Inline-стиль** | Атрибут `style="text-align: center;"` у `<h1>` | Выравнивание заголовка по центру |

### 2. CSS-переменные (`:root`)
Объявлены в `style.css` для централизованного управления дизайном:
- `--color-bg` — основной фон (чёрный `#0d0d0d`)
- `--color-surface` — фон карточек (тёмно-серый `#1a1a1a`)
- `--color-primary` — основной акцент (серебристый `#c0c0c0`)
- `--color-accent` — акцентный цвет (чёрный `#000000`)
- `--color-text` — цвет текста (светло-серый `#e0e0e0`)
- `--color-text-muted` — приглушённый текст (`#a8a8a8`)
- `--font-main` — основной шрифт (`'Segoe UI', Tahoma, sans-serif`)

### 3. Позиционирование
| Тип | Где применено | Зачем |
|-----|--------------|-------|
| `static` | `<footer>` (inline) | Явное указание стандартного поведения |
| `relative` | `.metallic-card` (секции) | Точка отсчёта для вложенного absolute-элемента |
| `absolute` | `.badge` (бейдж «TOP») | Привязка бейджа к углу карточки |

### 4. Псевдоклассы состояний
| Псевдокласс | Где применено | Эффект |
|-------------|--------------|--------|
| `:hover` | `.metallic-card`, `button`, `aside a` | Подъём карточки с длинной тенью; подсветка кнопки и ссылки |
| `:active` | `button` | Визуальное «вдавливание» кнопки при нажатии (`scale(0.97)`) |
| `:focus` | `button`, `input`, `textarea` | Свечение кнопки (`box-shadow: 0 0 10px`); подсветка рамки полей |
| `:visited` | `aside a` | Изменение цвета посещённой ссылки на серый |

### 5. Контрастность
- Фон страницы: `#0d0d0d` (почти чёрный)
- Основной текст: `#e0e0e0` (светло-серый)
- Коэффициент контрастности: **~15.5:1** (требование: не менее 4.5:1)

### 6. Стиль «Металлик»
- Карточки `.metallic-card` оформлены как металлические пластины:
  - Диагональный градиент `linear-gradient(145deg, #2a2a2a, #1a1a1a)` имитирует блик на металле
  - Серебристая акцентная полоса слева (`border-left: 4px solid`)
  - При наведении (`:hover`) карточка поднимается на 5px и отбрасывает длинную серебристую тень
- Кнопка «Отправить» с металлическим градиентом и свечением при фокусе
