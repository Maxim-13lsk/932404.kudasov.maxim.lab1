# Лабораторная работа №1 — Основы HTML и структура веб-страницы

## Описание
Персональная HTML-страница «О себе» в стиле техногика и обзорщика гаджетов.

**Вариант:** 12  
**Тема:** Техногик и обзорщик гаджетов

## Цель работы
Освоить базовую структуру HTML-документа, семантические теги, работу с текстом,
списками, ссылками и изображениями.

## Что реализовано
- Семантическая разметка: `<header>`, `<main>`, `<section>`, `<aside>`, `<footer>`
- Маркированный список навыков (`<ul>`)
- Нумерованный список проектов (`<ol>`)
- Изображение-аватар с атрибутами `src`, `alt`, `width`, `height`
- Форма обратной связи с полями: Имя (`type="text"`), Email (`type="email"`),
  Сообщение (`<textarea>`), кнопка отправки. У всех полей заданы `name` и `placeholder`.
- Адаптивная вёрстка (медиа-запрос для мобильных устройств)
- Цветовая гамма: серебристо-чёрная (хай-тек)

## Валидация
Код успешно прошёл проверку на [W3C Validator](https://validator.w3.org/).
